## 三、功能模块与实训流程参数

### 3.1 流程总览

实训分为 **4 个阶段、12 个步骤**，对应大纲编号 Q01～Q12：

| 阶段 | 步骤数 | 步骤编号 | 满分 |
|------|:------:|----------|:----:|
| 监测与准备 | 7 | Q01～Q07 | 25 分 |
| 数据采集 | 2 | Q08～Q09 | 32 分 |
| 数据处理 | 3 | Q10～Q12 | 43 分 |
| **合计** | **12** | — | **100 分** |

### 3.2 步骤明细参数

| 大纲 | 步骤 ID | 步骤名称 | 所属阶段 | 满分 | 主要任务 |
|:----:|---------|----------|----------|:----:|----------|
| Q01 | prep.tech | 前期技术准备 | 监测与准备 | 3 | 平面布置图选测斜管布设位置、填写测点间距 |
| Q02 | prep.material | 取料区域 | 监测与准备 | 2 | 选择正确材料库房领料 |
| Q03 | prep.assembly | 管材拼装 | 监测与准备 | 4 | 测斜管选型与拼装工艺配置 |
| Q04 | prep.cage | 导管安装到钢筋笼 | 监测与准备 | 4 | 截面选位、立面高度与绑扎设置 |
| Q05 | prep.inspection | 管口验收 | 监测与准备 | 4 | 识别管口缺陷并选择处置方案 |
| Q06 | prep.connectivity | 通畅性测试 | 监测与准备 | 4 | 通槽检测与结论判定 |
| Q07 | prep.initialMeasurement | 初测(基准测量) | 监测与准备 | 4 | 确认初测条件与基准数据有效性 |
| Q08 | acq.safety | 测前准备与安全防护 | 数据采集 | 6 | 环境条件、PPE、出发准备 |
| Q09 | acq.instrument | 读数仪设置与数据采集 | 数据采集 | 26 | CX-03E 读数仪完整采集流程（权重最高） |
| Q10 | data.processing | 数据导入与预处理 | 数据处理 | 5 | 连接仪器、选孔、补全累计位移 |
| Q11 | data.report | 监测日报表填写 | 数据处理 | 16 | 填写深层水平位移监测日报表 |
| Q12 | data.analysis | 多期数据分析与预警判断 | 数据处理 | 22 | 多期曲线对比、预警标注与等级判断 |

### 3.3 辅助功能

| 功能 | 说明 |
|------|------|
| **工程资料库** | 工程背景 PDF、仪器资料、管材资料、GB 50497 标准 PDF |
| **框架导览** | 实训整体框架与步骤关系说明 |
| **多期曲线图** | 8 期监测数据可视化（ECharts） |
| **抖动公式演练场** | 数据抖动/公式理解辅助工具（开发调试用，Ctrl+Shift+Alt+K 切换开发面板） |
| **线框标注模式** | 需求对照与 UI 走查 |
| **进度持久化** | localStorage 保存答题、草稿、完成状态；切换步骤或刷新不丢失 |
| **成绩报告** | 提交后生成含模块得分、逐题正误与解析的报告页 |

## 五、评分与考核参数

### 5.1 题型支持

| 题型 | 代码 | 说明 |
|------|------|------|
| 单选题 | singleChoice | 唯一正确答案 |
| 多选题 | multiChoice | 多选组合判分 |
| 数值填空 | fillValue | 精确或规定格式答案 |
| 范围填空 | fillRange | 数值落在正确区间内得分 |

### 5.2 成绩等级（满分 100）

| 等级 | 分数区间 |
|------|----------|
| 优秀 | ≥ 90 |
| 良好 | 80～89 |
| 中等 | 70～79 |
| 及格 | 60～69 |
| 不及格 | ＜ 60 |

### 5.3 交互与状态规则

- 学员完成答题后，**切换步骤或刷新页面** 须保持已选答案与完成状态。
- 已保存状态 **仅可通过显式重置** 清除。
- 已完成题目按钮保留原判断项文字，状态标记由 `[?]` 改为 `[v]`。
- 成绩报告 **仅展示已有有效答题或得分记录的步骤**；未作答任务记 0 分，显示「未作答」。

### 5.4 数据存储

| 参数 | 值 |
|------|-----|
| 存储方式 | 浏览器 localStorage |
| 会话键名 | `ioxweb.training.session.v1` |
| 会话版本 | 1 |
| 存储内容 | submissions、drafts、results、completedSteps |

## 八、非功能需求参数

| 类别 | 要求 |
|------|------|
| **可用性** | 步骤导航清晰；关键操作有任务说明与示意图 |
| **一致性** | 工业风 UI：高对比边框、等宽标注、步骤序号 01～12 |
| **可维护性** | 题目与步骤以 CSV 配置为主，减少硬编码 |
| **可扩展性** | 步骤 ID（prep.* / acq.* / data.*）与 appStepId（1～12）映射可增删步骤 |
| **教学合规** | 工程数据为典型化示例，文档注明不代表真实项目 |
| **无障碍（基础）** | 表单与按钮具备可读标签；色觉依赖辅以文字状态 |

## 九、产品边界与规划项

### 9.1 当前版本范围内

- 单用户本地实训与评分
- 12 步完整流程与 100 分制报告
- 工程资料在线查阅（PDF）

### 9.2 当前版本范围外（规划/对接）

- 学员账号登录与班级管理
- 教师端成绩汇总、批量导出
- 服务端成绩持久化与防作弊
- 多工程案例切换
- VR/AR 现场沉浸（无）
