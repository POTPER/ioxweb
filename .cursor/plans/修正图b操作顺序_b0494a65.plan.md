# 修正图 B 操作顺序（一张大图，分步修改）

## 书写规则

- 时序图 **只用中文业务含义**，不写代码接口。
- **有顺序约束**：`alt`（如接线 vs 开机）。
- **无顺序约束**：并列 `opt`（如测孔参数与探头设置；测量间距与设置朝向和靠齐方位）。

**`loop` 何时使用**：正测 **5 次手测** 等固定次数重复 **可用 `loop`**。

**`opt` vs 必经步骤**：无先后、可进可不进的菜单用 **并列 `opt`**（如主菜单测孔参数、正测时「测量间距 ∥ 朝向靠齐」、**第 6 步补测 ∥ 收工**）。**必经、有顺序**的步骤用 **顺序箭头** 或 **`alt`**（如测点间上提/下放、反测前重新确定朝向并选择靠齐）。**`opt` 内** 若学员选择执行，仍可用 **`alt`** 区分对错（如收工 opt 内的先关电源后拔线）。

**`alt` 与 loop 的配合**：`loop 手测第1至5点` 表示 **第 1～5 点每点都要** 稳定 → OK 记点；`alt` **不是** 把第 5 点排除在手测之外，而是描述 **记点完成之后** 的分支（第 1～4 点 → 上提/下放；第 5 点 → 结束手测）。

## 第 2 步：读数仪设置（范围定稿）

**读数仪设置**包含两块，均为 **可选行为**（`opt`），**块与块之间无先后顺序**：


| 菜单项        | 包含字段 / 说明                        |
| ---------- | -------------------------------- |
| **测孔参数设置** | 测区编号、孔号、孔深（**保存** 仅标记已保存，**不写** 答案缓存） |

### 调用已保存参数，影响其它面板

| 已保存项 | 影响 |
|----------|------|
| 探头 **步长** | 采集表行距、剖面间距与上提/下放步进 |
| 探头 **方向** | 剖面初始深度、上提/下放方向 |
| 测孔 **测区编号、孔号、孔深** | 测量显示；**「开始新的测量」时写入答案缓存并参与评分** |
| 探头 **方向、步长** | 采集逻辑同上；**评分写入时机同测孔参数** |
| 采集表 **组号** | 按任务组号生成各行（如 05 组） |

| 面板 | 变化 |
|------|------|
| **测斜管剖面** | **解锁**；设定初始测点 **显示**；**上提/下放** 位移 |
| **采集表** | **按步长生成空表**；接收记点/补测/自动采集数据并 **展示结果** |
| **测斜管平面** | **解锁**；**重置** 旋转、朝向确认、靠齐方位 |
| **读数仪** | 进入 **正向测量确认屏**，提示先完成现场布置 |

### 重置补测与采集数据

- **清空采集表**中已有正测、反测读数（含此前 **补测写入** 的数据）→ 消息发往 **采集表** 对象。
- **重置** 现场布置（朝向、靠齐、间距需重做）。
- **清除** 收工相关答案缓存。

补测界面上的组号/深度/方向输入仍保留；**采集表已清空**，需重新测量后再补测。

### 参数评分边界（设计定稿，待实现）

#### 保存值与提交值（核心关系）

测孔/探头场景的本质是 **两种值的来源不同**：

| 概念 | 含义 | 代码载体 | 何时更新 |
|------|------|----------|----------|
| **保存值** | 学员在 LCD 测孔/探头屏点 **保存** 后，读数仪 **本机认作已配置** 的参数 | `params` / `probe` + `paramsSaved` / `probeSaved` | 每次 **保存**（含第 6 步回主菜单后再保存） |
| **提交值** | **提交练习** 时参与评分的答案 | `recordedAnswers` 中各 `questionId` | 按 **业务节点** 写入；整包在 **提交练习** 时算分 |

**关系（测孔/探头 5 项）**：

```text
保存值  ──≠──  提交值（默认不自动同步）

保存         →  只更新保存值
开始新的测量 →  用当前保存值开测，并把此时保存值「抄送」为提交值（写入答案缓存 5 项）
之后再保存   →  保存值变，提交值不变（已采数据也不变）
再次开测     →  提交值 5 项被新一轮保存值覆盖
提交练习     →  只对已写入的提交值算分（读整包 recordedAnswers）
```

**一句话**：**保存值** = LCD 配置草稿；**提交值** = 计分用的答卷。测孔/探头 **提交值只在「开始新的测量」时从保存值拷贝一次**；第 6 步再改并保存只动保存值，**不动** 已定格的提交值。

**软件责任**：避免「保存值最后一次写入」误当成「提交值」，导致 **提交分** 与 **采集表** 不一致。  
**用户责任**：开测后自行改保存值、再点「开始新的测量」用新参数重测 — 后果由用户操作引起，不是设计缺陷。

**其它题目**（线材、读数、补测、收工等）：无「保存/开测」二分，**操作即写入提交值**（做了才有提交值，不做则提交时无该项）。

#### 两层数据机制（与上表对应）

| 机制 | 对应 | 用途 |
|------|------|------|
| **保存值 / 会话缓存** | `params`/`probe`、`localStorage.progress` | 续练、LCD 显示、能否点「开始新的测量」 |
| **提交值 / 计分答卷** | `recordedAnswers` → 提交练习 | **唯一算分依据** |

```text
保存           →  仅更新保存值
开始新的测量   →  保存值 → 采集；保存值 → 提交值（5 项）
提交练习       →  读取提交值整包算分
```

**当前 bug**：保存时 `recordAnswer` 把 **保存值** 误写入 **提交值**，与开测采集脱钩。

| 动作 | 保存值 | 提交值 |
|------|--------|--------|
| 测孔/探头 **保存** | 更新 | 不写 |
| **开始新的测量** | 用于开测 | 拷贝当前保存值（5 项） |
| 开测后再 **保存**（含第 6 步） | 更新 | **不变** |
| **再次** 开始新的测量 | 用于新一轮 | 覆盖 5 项 |
| **提交练习** | — | 整包算分 |

**实现**：[`Step9_InstrumentSetting.tsx`](src/components/steps/Step9_InstrumentSetting.tsx) 保存分支去掉 5 项 `recordAnswer`；「开始新的测量」分支写入提交值。

### 第 3 步续：现场布置（已定稿）

进入 **正向测量确认屏** 后须完成布置；**测量间距、朝向、靠齐三项都完成** 后，读数仪才允许按 OK 进入测点采集环境。

| 动作 | 板块 | 顺序关系 |
|------|------|----------|
| **设置测量间距** | 测斜管剖面 | 与「设置朝向和靠齐方位」**同级**，无先后（并列 `opt`，不用 `loop`） |
| **设置朝向和靠齐方位** | 测斜管平面 | 一个 `opt` 内顺序完成：先 **确定朝向**，再 **选择靠齐**（靠齐须在朝向之后） |

**`opt` 命名**：平面侧整块称为 **设置朝向和靠齐方位**，不用单独的 `opt 设置朝向`。

- 外层 `opt 设置朝向和靠齐方位`：与 `opt 设置测量间距` 无先后。
- **内部顺序**：确定朝向 → 选择靠齐。

```text
opt 设置测量间距
  …
end

opt 设置朝向和靠齐方位
  旋转并确定朝向 → 记录朝向
  选择靠齐方位   → 记录靠齐方位
end
```

### 三项齐备 → 确认屏 → 按 OK 进入测点环境

| 状态 | 读数仪确认屏 | 按 OK |
|------|----------------|-------|
| **任一项未完成** | 红色提示 **请先完成现场布置** | **无效** |
| **三项均已完成** | 红色提示消失，视为 **现场布置完毕**；显示 **按OK键开始测量** | **有效** → 进入 **测点采集环境**（采集屏、稳定倒计时、剖面深度同步） |

### 时序图写法

```text
opt 设置测量间距 …
opt 设置朝向和靠齐方位
  确定朝向 → 记录朝向
  选择靠齐方位 → 记录靠齐方位
alt 三项未齐 / 三项已齐 → 按OK
```

### 第 4 步：正测手测 5 点（已定稿）

进入测点采集环境后，**手测第 1～5 点**（`loop` 5 轮），**第 6 点起** 由读数仪 **自动测量** 并写入采集表。

**测点划分**：

| 阶段 | 测点 | 操作 |
|------|------|------|
| **手测** | 第 **1～5** 点 | 稳定 → OK 记点；第 1～4 点记点 **必须** 上提/下放 |
| **自动测量** | 第 **6** 点及以后 | 第 5 点记点完成后触发；读数仪自动填充采集表剩余各行 |

示例（探头向上、步长 0.5 m）：手测 **20.0 / 19.5 / 19.0 / 18.5 / 18.0 m**（第 1～5 点）→ 自动测量从 **17.5 m**（**第 6 点**）起至表底。

### 剖面 vs 读数仪 vs 采集表：分工

| 对象 | 控制参数 | 管什么 |
|------|----------|--------|
| **读数仪屏幕** | **步长** | 当前测点深度、显示读数、稳定倒计时、按 OK 记下的数值 |
| **采集表** | **步长**（行结构） | **接收** OK 记点、补测、自动采集写入的数据；**展示** 深度/组号/正测/反测/校验和 |
| **测斜管剖面** | **步长**（测点标签）+ **测量间距**（位移） | 探头动画与深度标签；**上提/下放移动距离** 仅由测量间距控制；📋 可 **打开** 采集表查看 |

**记点数据流**：`读数仪 --按OK记点--> 答案缓存` + `读数仪 --写入--> 采集表 --展示--> 采集表`

剖面 **不替代** 采集表接收数据；采集表是独立的 **接收与展示** 对象。

**测量间距** 的作用范围 **仅限剖面图**：

- 只影响 **▲ 上提 / ▼ 下放** 时剖面里探头 **视觉上移动多少**（一个测量间距）。
- **不** 决定采集表有哪些深度行。
- **不** 决定读数仪 LCD 显示哪深度、何读数。

**步长** 的作用范围：

- 读数仪 **5 个手测点** 的深度序列与屏显读数。
- 采集表 **行深度** 与记点写入位置。
- 剖面 **当前测点序号/深度标签** 与采集表、读数仪对齐。

任务正确时步长与测量间距均为 **0.5 m**；设错时剖面位移与屏显/表行可能 **不一致**，便于评分。

任务示例（探头向上、步长 0.5 m）：手测深度 **20.0 → 19.5 → 19.0 → 18.5 → 18.0 m**（5 点，由步长决定）。

### 单次循环（共 5 次，第 1～5 点均需记点）

| 步骤 | 说明 |
|------|------|
| 1 | **读数仪** 按 **步长** 显示当前测点读数（稳定前波动）；**剖面** 同步显示同序号测点位置 |
| 2 | **等待稳定**：第 1 点 **30 s**；第 2–5 点各 **5 s** |
| 3 | 稳定后 **按 OK** → **第 1～5 点每点都要记点**；**答案缓存** 记录；**采集表** 按 **步长** 对应行 **接收并显示** 正测读数 |
| 4 | **记点之后** `alt`：**第 1～4 点** → 必须在剖面按 **测量间距** 上提/下放，进入下一点；**第 5 点** → 手测结束 |
| 5 | **第 5 点**记点完成后：**从第 6 点起自动测量** → 采集表补全 → **反向测量确认** |

**上提/下放不是 opt**：测点间 **必经** 步骤。

### 时序图要点（强调双轨）

```text
loop 手测第1至5点
  …稳定、OK记点（第1～5点每点都要）…
  alt 第1至5点记点之后
    alt 第1至4点：剖面上提/下放 → 进入下一点
    else 第5点：手测结束
  end
end

Note: 从第6点起自动测量
读数仪 → 采集表：自动采集第6点及以后各深度
采集表：显示完整正测列
→ 反向测量确认
```

### 第 5 步：反测（已定稿）

正测第 6 点起自动采集完成后，**一定进入反测阶段**（读数仪自动切至 **反向测量确认屏**，**不可跳过**、非可选菜单）。

### 反测前：重新布置（平面）

| 与正测对比 | 说明 |
|------------|------|
| **必经** | 正测完成后自动进入，学员必须完成反测采集才能继续后续流程 |
| **朝向 + 靠齐** | **须按顺序重做**（**不用 `opt`**）：先 **确定反测朝向**，再 **选择反测靠齐方位**（靠齐须在朝向之后） |
| **测量间距** | **沿用** 正测已设值（剖面不重做间距）；确认屏仍检查间距已设 |

正测 autoCollect 结束时系统会：**清空靠齐方位**、**探头翻转至反测朝向**（如 A− / 180°）。学员须在平面 **按顺序** 重新确认朝向并选择靠齐——与正测不同，正测时「间距 ∥ 朝向靠齐」为并列 **`opt`**；反测时平面布置为 **必经顺序步骤**。

### 反测确认屏 → 采集

| 状态 | 反向测量确认屏 | 按 OK |
|------|----------------|-------|
| **朝向、靠齐或间距未完成** | **请先完成现场布置** | **无效** |
| **布置完毕** | 显示 **按OK键开始测量** | **有效** → 进入 **反测采集环境** |

### 反测采集：与正测相同流程

| 阶段 | 测点 | 操作 |
|------|------|------|
| **手测** | 第 **1～5** 点 | 稳定 → OK 记点 → 写入采集表 **反测列**；第 1～4 点记点后 **必须** 上提/下放 |
| **自动测量** | 第 **6** 点及以后 | 第 5 点记点完成后触发；读数仪自动填充采集表剩余 **反测** 读数并重算 **校验和** |

- **loop**、稳定时间（第 1 点 30 s / 第 2～5 点各 5 s）、步长 vs 测量间距分工、记点数据流：**与第 4 步正测相同**。
- 区别：LCD 标题为 **反向测量**；读数取 **A−**；采集表写入 **反测列**。
- 反测 autoCollect 完成后 → **返回主菜单**（phase 5），剖面/平面再次锁定。

### 时序图要点

```text
正测第6点起自动采集完成
→ 反向测量确认屏（必经）

Note: 平面布置必经 非opt
学员 → 平面：确定反测朝向 → 答案缓存
学员 → 平面：选择反测靠齐 → 答案缓存
（测量间距沿用正测）

alt 布置未齐 / 布置完毕 → 按OK
→ 反测采集环境

loop 手测第1至5点（同正测结构）
  alt 第1至5点记点之后
    alt 第1至4点：上提/下放
    else 第5点：手测结束
  end
end

从第6点起自动采集反测读数
→ 主菜单
```

### 第 6 步：补测、收工与提交（已定稿）

反测 autoCollect 完成 → **返回主菜单**（phase 5）。

**补测** 与 **收工** 在流程上 **都是可选**（`opt`）：规范操作里 **建议** 做，但学员 **可以不做**，直接 **提交练习**；**不做则对应题目不会写入答案缓存**，提交时该项按 **未答 / 不得分** 处理，**不阻断** 提交。

```text
主菜单
  opt 补测数据点   ← 可跳过
  opt 收工         ← 可跳过
（任意时刻）提交练习
```

**提交练习** 与上述 **并行**，见下。

#### 提交练习：自始至终可用

| 要点 | 说明 |
|------|------|
| **位置** | **任务说明** 板块底部按钮 |
| **时机** | 练习页进入后 **任意阶段** 均可点击 |
| **与补测/收工关系** | **不依赖** 补测或收工完成；跳过后仍可提交 |
| **流程** | 点击 → 确认 → 读取 **已有** 答案缓存算分 → 练习报告 |

#### 补测（`opt`，可跳过）

| 操作 | 答案缓存 | 采集表 |
|------|----------|--------|
| **开始补测** | 写入组号、深度、方向 | 更新对应深度行 |
| **返回未补测 / 不做** | **不写入** | 不变 |

与第 2 步主菜单 **同一 `opt`** 结构；反测完成后 **可选用**（如 12.5 m 反测校验和异常）。

#### 收工（`opt`，可跳过）

学员 **可选用** 关电源、拔线；**不做** 则 `cleanupOrder` **不在答案缓存**。

**若做收工**，框内用 `alt` 区分顺序（与第 1 步对称，**不是** 把整个收工改成必经）：

| 顺序 | 操作 | 答案缓存 |
|------|------|----------|
| **正确** | 先关机 → 再拔线 | 记录 **先关电源后拔线** |
| **错误** | 未关机就点拔线 | 探头口不可操作；**仍不写入** 正确收工项 |

#### 时序图要点

```text
Note（大图开头）: 提交练习自始至终均可点击

反测完成 → 主菜单

opt 补测（可跳过，不做则不写答案缓存）
opt 收工（可跳过；若做则 alt 先关电源后拔线）

（任意时刻）提交练习 → 仅对已写入答案缓存的项算分
```

## 正文：读数仪设置字段与评分（不进时序图）

### 测孔参数设置（三项）


| 字段   | 任务正确值（文档表） |
| ---- | ---------- |
| 测区编号 | 03         |
| 孔号   | 06         |
| 孔深   | 20 m       |


时序图表述（均在同一 `opt 测孔参数设置` 内）：

1. 进入测孔参数设置
2. 设置测区编号、孔号、孔深（屏内三项，编辑顺序不限）
3. **保存**：读数仪 **标记测孔参数已保存**（`paramsSaved`）；**不写入答案缓存**
4. **按返回退出、未点保存**：屏上修改 **不保留** 到开测配置

**评分写入**：仅在 **开始新的测量** 时，将当前已保存的测区/孔号/孔深 **一次性写入答案缓存**（与本次采集所用参数一致）。

### 探头设置（两项）


| 字段  | 任务正确值（文档表） |
| --- | ---------- |
| 方向  | 向上         |
| 步长  | 0.5 m      |


时序图：设置方向、设置步长 → **保存** 时 **标记探头已保存**（`probeSaved`），**不写答案缓存**；**返回未保存** 则屏上修改作废。**评分** 在 **开始新的测量** 时与测孔参数一并写入。

### 时间设置（只读界面）

- 主菜单可 **可选进入**（`opt`），与测孔参数、探头设置 **无先后顺序**。
- 界面显示 **当前系统时间**（年/月/日/时/分），**不可编辑**。
- 学员可移动光标浏览，按 **确认** 或 **返回** 回主菜单。
- **不写入答案缓存**，**不参与评分**。

### 补测数据点（三项设置 + 开始补测）

| 字段 | 任务正确值（文档表，示例） |
|------|---------------------------|
| 组号 | 05 |
| 深度 | 12.5 m |
| 方向 | 反测 |

时序图（`opt 补测数据点` 内，**列出三项**）：

1. 进入补测数据点  
2. 设置组号、深度、方向（屏内三项，编辑顺序不限）  
3. **点击开始补测**：  
   - 答案缓存写入 **组号、深度、方向** 三条  
   - 进入补测流程（LCD 模拟采集中）  
   - **采集表** 在 **对应深度** 更新读数（按方向更新正测或反测列，重算校验和）  
   - 完成后返回主菜单  
4. **按返回退出、未点开始补测**：三项 **均不** 写入答案缓存  

说明：主菜单随时可进入补测界面；**采集表写入** 需该深度行已存在（通常正测、反测完成后对异常深度补测，如 12.5 m 反测）。

### 组合关系

- 第 2 步主菜单相关行为均为 **并列 `opt`**：测孔参数、探头设置、时间设置、补测数据点（**不用 `loop`**）。
- 测孔参数与探头设置无前后依赖；时间设置、补测数据点可随时进入。
- **测孔参数 + 探头设置均保存后** →「可开始测量」；时间设置、补测入口与此解锁条件无关（但补测改表通常在采集阶段之后才有意义）。
