# 成绩报告

用于展示学生完成实训后的总成绩、分步骤得分、题目作答情况、标准答案和解析。报告应优先保证信息对齐、阅读效率和空间利用率，尤其要处理答案长短不一致时的排版稳定性。

## 元素

### 报告总览区

- 标题：主标题为"成绩报告"
- 副标题：显示具体实训名称，例如"深基坑深层水平位移监测实训"
- 学生信息：姓名 / 学号 / 班级
- 考试信息：完成时间 / 总用时 / 总得分
- 总成绩卡片：当前总分、满分、成绩等级
- 能力雷达图：按能力维度展示得分占比

### 步骤汇总区

- 按步骤分组展示题目结果
- 每个步骤显示：步骤名称 / 题目数量 / 步骤得分 / 得分进度条
- 步骤得分低于 60% 时使用弱项样式提示

### 题目标题栏

- 左侧固定宽度：答题状态图标 + 题目名称
- 中间自适应宽度：`你的答案：xxx`（完整显示，允许换行）
- 右侧固定宽度：题目得分
- 中间分隔符统一使用半角竖线 `|`
- 标题栏格式：`题目名称 | 你的答案：xxx | 当前得分/满分分`
- 得分格式：`1/1分`、`0/2分`
- 长答案自动换行显示，不允许挤压右侧得分
- 未作答显示为"未作答"
- 标题栏显示完整答案是为了节约空间，用户无需展开即可快速浏览所有作答情况

## 验收

- 错题标题栏可直接看到题目名称、你的完整答案和得分
- 正确题在 `mistakesOnly` 模式下不展开，但仍显示你的完整答案和得分
- 错题展开区域只包含标准答案和解析（不重复显示你的答案）
- 桌面端标准答案与解析左右对齐
- 移动端标准答案与解析正常上下堆叠
- 长答案自动换行显示，不会遮挡右侧得分
- 右侧得分固定宽度，永不被挤压
- 标题栏使用 flex 布局，支持内容换行
- TypeScript 检查通过：`npm run lint`
