# 成绩报告

成绩报告用于查看各实训步骤的答题结果和得分情况，由教师端管理展示、下载；在客户端不展示。

## 元素

### 基本信息

- 主标题显示为成绩报告。
    - 副标题显示实训名称。
- 学生信息显示学生姓名、学号、班级、完成时间。总成绩显示实际总得分、总满分和等级。

    - 等级：根据总成绩计算，满分100分，90分以上为优秀，80-89分为良好，70-79分为中等，60-69分为及格，60分以下为不及格。
    - 总得分：实际总得分
    - 总满分：总满分
    - 学生姓名：登录账号姓名
    - 学号：登录账号学号
    - 班级：登录账号班级
    - 完成时间：学生完成本次实训并提交报告的物理时间

### 得分明细

- 由实训步骤（如：前期技术准备）、得分、用户答题组成
    - 实训步骤：实训页面左侧的步骤名称（12项）
    - 得分：该步骤中所有任务的得分总和
    - 用户答题：该步骤下所有任务的答题情况
        - 正确：正确图标/任务名称/用户答案/得分
            - 任务存在可评分的提交记录，且评分结果为满分或符合正确判定时，视为正确答题。
        - 错误：错误图标/任务名称/用户答案/得分 + 正确答案/解析
            - 有提交记录但提交内容不符合评分规则，或任务没有提交答案时，均视为错误答题；没有提交答案时用户答案显示为“未作答”。
