## 文件说明

### pages.csv - 需求文档内容

使用 CSV 格式存储 Markdown 内容的需求文档。

**字段说明：**

| 字段 | 说明 | 示例 |
|------|------|------|
| pageId | 页面唯一标识符 | score-report |
| title | 页面标题 | 成绩报告 |
| subtitle | 页面副标题 | 成绩报告功能需求文档 |
| content | Markdown 格式的完整内容 | # 成绩报告\n\n用于展示... |

## Markdown 格式规范

### 1. 章节结构

使用二级标题（##）定义章节：

```markdown
## 元素

### 报告总览区

- 标题：主标题为"成绩报告"
- 副标题：显示具体实训名称
```

**渲染效果：**
- 二级标题（##）会被解析为可折叠的章节
- 三级标题（###）会被解析为子章节标题
- 列表项（-）会自动添加绿色勾选图标

### 2. 支持的 Markdown 语法

#### 代码标记

使用反引号包裹代码片段：

```markdown
中间自适应宽度：`你的答案：xxx`（完整显示，允许换行）
```

**渲染效果：** 中间自适应宽度：`你的答案：xxx`（完整显示，允许换行）

#### 加粗强调

使用双星号包裹重要文本：

```markdown
**标题栏显示完整答案是为了节约空间，用户无需展开即可快速浏览所有作答情况**
```

**渲染效果：** **标题栏显示完整答案是为了节约空间，用户无需展开即可快速浏览所有作答情况**（绿色加粗）

#### 列表

使用短横线（-）创建列表：

```markdown
- 项目 1
- 项目 2
- 项目 3
```

**渲染效果：**
- ✓ 项目 1
- ✓ 项目 2
- ✓ 项目 3

### 3. CSV 特殊字符处理

由于内容包含逗号、引号和换行符，需要用双引号包裹整个 content 字段：

```csv
pageId,title,subtitle,content
score-report,成绩报告,成绩报告功能需求文档,"# 成绩报告

用于展示学生完成实训后的总成绩、分步骤得分、题目作答情况、标准答案和解析。

## 元素

### 报告总览区

- 标题：主标题为""成绩报告""
- 副标题：显示具体实训名称"
```

**规则：**
- 整个 content 字段用双引号包裹
- 内容中的双引号需要转义为两个双引号（`""`）
- 换行符直接使用，不需要转义

## 编辑工作流

### 1. 添加新页面

在 `pages.csv` 中添加一行：

```csv
new-page,新功能,新功能需求文档,"# 新功能

新功能的概述说明...

## 功能特性

- 功能 1：说明
- 功能 2：说明

## 验收标准

- 验收项 1
- 验收项 2"
```

然后在 `src/data/requirementsData.ts` 中添加类型：

```typescript
export type RequirementPage = 
  | 'score-report'
  | 'training-steps'
  | 'data-processing'
  | 'multi-period-analysis'
  | 'new-page';  // 新增
```

### 2. 修改内容

直接在 CSV 文件中修改对应行的 content 字段。

**提示：** 建议使用支持多行编辑的工具（如 VS Code）来编辑 content 字段。

### 3. 内容模板

```markdown
# 页面标题

页面概述说明...

## 章节 1

### 子章节 1-1

- 项目 1
- 项目 2：使用 `代码` 标记
- **项目 3：重要内容加粗**

### 子章节 1-2

- 项目 4
- 项目 5

## 章节 2

- 直接列表项 1
- 直接列表项 2

## 验收标准

- 验收项 1
- 验收项 2
- 验收项 3
```

## 推荐编辑工具

### 1. VS Code（推荐）
- ✅ 支持多行编辑
- ✅ 语法高亮（安装 Rainbow CSV 插件）
- ✅ 支持 Markdown 预览
- ✅ 轻量级

**编辑步骤：**
1. 打开 `pages.csv`
2. 找到要编辑的行
3. 点击 content 字段，按 `F2` 进入编辑模式
4. 编辑 Markdown 内容
5. 保存文件

### 2. Excel / WPS 表格
- ✅ 可视化编辑
- ⚠️ 不支持多行显示，需要在单元格中编辑
- ⚠️ 保存时选择 CSV UTF-8 格式

### 3. 在线 Markdown 编辑器 + CSV 合并
- ✅ 先在 Markdown 编辑器中编写内容
- ✅ 然后复制到 CSV 文件中
- 推荐：[StackEdit](https://stackedit.io/)、[Dillinger](https://dillinger.io/)

## 注意事项

1. **编码格式**：确保 CSV 文件使用 UTF-8 编码
2. **换行符**：使用 LF（\n）而不是 CRLF（\r\n）
3. **引号转义**：content 字段中的双引号需要转义为 `""`
4. **Markdown 格式**：
   - 使用 `##` 定义章节（会被解析为可折叠章节）
   - 使用 `###` 定义子章节标题
   - 使用 `-` 定义列表项（会自动添加勾选图标）
   - 使用 \`code\` 标记代码
   - 使用 \*\*text\*\* 加粗文本
5. **重启服务器**：修改 CSV 文件后需要重启开发服务器

## 常见问题

### Q: 如何在 Excel 中编辑多行内容？
A: 在单元格中按 `Alt + Enter` 可以换行。保存时选择 CSV UTF-8 格式。

### Q: 如何快速复制 Markdown 内容到 CSV？
A: 
1. 在 Markdown 编辑器中编写内容
2. 复制整个内容
3. 在 VS Code 中打开 CSV 文件
4. 找到对应行的 content 字段
5. 用双引号包裹，粘贴内容
6. 将内容中的双引号替换为 `""`

### Q: 为什么我的内容没有显示？
A: 检查以下几点：
1. content 字段是否用双引号包裹
2. 内容中的双引号是否转义为 `""`
3. 是否重启了开发服务器
4. 运行 `npm run lint` 检查是否有语法错误

### Q: 如何添加图片？
A: 当前不支持图片，建议使用文字描述或链接。

### Q: 如何添加表格？
A: 使用子章节结构模拟表格，或使用文字描述。

## 优势

相比之前的多文件 CSV 方案，新方案的优势：

1. **更简单**：只需要一个 CSV 文件
2. **更直观**：直接编写 Markdown，所见即所得
3. **更灵活**：支持任意 Markdown 结构
4. **更易维护**：内容集中在一个文件中
5. **更易协作**：可以使用 Markdown 编辑器编写，然后复制到 CSV
